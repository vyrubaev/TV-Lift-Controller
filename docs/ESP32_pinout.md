ESP32-WROOM-32 — карта выводов

**Плата:** TV Lift Controller REV_A  
**Модуль:** ESP32-WROOM-32  
**Источник истины для прошивки:** `BoardConfig`

## Назначение GPIO

| GPIO | Направление | Назначение | Примечание |
|---:|---|---|---|
| 0 | вход | `ETH_RETCLK` | Вход внешнего RMII REF_CLK 50 МГц; strapping-пин. PHY не должен выдавать clock до завершения boot. |
| 1 | выход | `UART_TX_PIN` | UART0 TX / RS-232. Используется также для загрузочных сообщений. |
| 2 | выход | `IR_TRANSMITTER` | Strapping-пин; не подтягивать к +3.3 V при reset. |
| 3 | вход | `UART_RX_PIN` | UART0 RX / RS-232. |
| 4 | вход | `LIMIT_SWITCH_UP_PIN` | Верхний концевик. Обрабатывать аппаратным GPIO-прерыванием. |
| 5 | выход | `CAN_TX_PIN` | Strapping-пин, внешняя подтяжка к +3.3 V допустима и соответствует штатному уровню `1`. |
| 12 | выход | `MOTOR1_PWM` | Strapping-пин MTDI. Во время reset должен оставаться `0`; запрещена внешняя подтяжка к +3.3 V. |
| 13 | вход | `LIMIT_SWITCH_DOWN_PIN` | Нижний концевик. Обрабатывать аппаратным GPIO-прерыванием. |
| 14 | вход | `IR_RECEIVER` | Вход ИК-приёмника. |
| 15 | вход | `CAN_RX_PIN` | Strapping-пин MTDO, внешняя подтяжка к +3.3 V допустима и соответствует штатному уровню `1`. |
| 16 | выход | `MOTOR1_INA` | Направление A драйвера VNH5019. |
| 17 | выход | `MOTOR1_INB` | Направление B драйвера VNH5019. |
| 18 | выход | `ETH_MDIO` | RMII MDIO. |
| 19 | выход | `ETH_TX0` | RMII TXD0. |
| 21 | выход | `ETH_TX_EN` | RMII TX_EN. |
| 22 | выход | `ETH_TX1` | RMII TXD1. |
| 23 | выход | `ETH_MDC` | RMII MDC. |
| 25 | вход | `ETH_RX0` | RMII RXD0. |
| 26 | вход | `ETH_RX1` | RMII RXD1. |
| 27 | вход | `ETH_CRS_DV` | RMII CRS_DV. |
| 32 | вход, ADC | `MOTOR1_CURR_SENS` | Измерение тока двигателя. |
| 33 | вход | `MOTOR1_DIAG` | Авария драйвера VNH5019. Обрабатывать GPIO-прерыванием. |
| 34 | вход | `DRY_CONTACT_DOWN_PIN` | Выход оптопары сухого контакта «вниз». Только вход, внутренней подтяжки нет. |
| 35 | вход | `DRY_CONTACT_UP_PIN` | Выход оптопары сухого контакта «вверх». Только вход, внутренней подтяжки нет. |
| 36 | вход | `ENC_A` | Канал A энкодера. Только вход. |
| 39 | вход | `ENC_B` | Канал B энкодера. Только вход. |
