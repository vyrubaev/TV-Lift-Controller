# TVLift Controller

Профессиональная платформа управления лифтом для телевизора на базе ESP32.

Проект включает в себя:

- прошивку контроллера ESP32;
- мобильное приложение;
- сервер обновлений и управления;
- веб-панель администратора;
- аппаратную документацию;
- систему удаленного обновления прошивки (OTA — Over-the-Air);
- полную инженерную документацию.

---

# Основные возможности

- управление электроприводом лифта;
- поддержка Wi-Fi и Ethernet;
- первоначальная настройка через Captive Portal;
- безопасное удаленное обновление прошивки;
- хранение настроек во Flash памяти;
- REST API для мобильного приложения;
- журнал событий;
- диагностика устройства;
- поддержка нескольких аппаратных ревизий.

# Основные принципы разработки

Проект строится по следующим правилам:

- модульная архитектура;
- минимальная связанность модулей;
- отсутствие глобальных переменных;
- отсутствие динамического выделения памяти в рабочем режиме;
- аппаратная независимость бизнес-логики;
- документирование всех архитектурных решений;
- обязательное код-ревью перед слиянием изменений.
